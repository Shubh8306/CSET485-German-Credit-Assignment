CSET485 AI and Society Assignment 1 - German Credit Analysis


This repository contains the Google Colab notebook used for CSET485 Assignment 1.

Dataset: German Credit Data

Random State: 25

Train/Test Split: 70% Training, 30% Testing

The notebook contains:

- Data preprocessing
- OLS Linear Regression
- Logistic Regression
- Model comparison
- Subgroup analysis
- Omitted-variable bias analysis
- Adversarial subset analysis
- Fairness analysis using DP, EO and PP
